# 栖野 · Wild Studio

一款偏向**漫游、造景与留影**的浏览器体素沙盒。世界没有任务、等级或材料门槛：找到喜欢的地方，用方块布置它，换一种光，再按下快门。

原生 WebGL2，零运行时依赖。直接打开 `index.html` 即可游玩。地形、方块贴图、动物与音效均由代码生成。

方块材质以 64×64 像素渲染，含细颗粒纹理；石头、草地、沙地等地形有多种固定纹理变化。云层边缘使用平滑的程序化噪声。

雪山采用大型连续群峰与弯曲冰川谷：裸岩峰顶、积雪坡面和谷中石砌前哨。前哨旁的苔石人形雕像已移除。远山的可见范围扩展至约 700 格，完整地形视距默认 10 区块、最高 12 区块；远景网格会先做一次平滑，山脊不再是一排尖刺。区域地貌的排列会随种子打乱，山体、谷宽与出生点也会变化；地表还散落着按种子生成的小屋、石塔、营地、花园、水井与废墟。载入旧存档时会尝试在本机保留一份地形变更前的备份。

运行时的新区块生成与网格构建放在后台线程，减少漫游时的画面停顿；不支持后台线程的浏览器会自动沿用原路径。区块网格合并进少量共享大缓冲，视野内的可见区块每帧按页一次提交，绘制命令从每区块一条降到每页一条；透明的水面与玻璃按远近顺序合在一起提交。浏览器不支持 multi-draw 时会自动退回逐页绘制。天空着色只填充没有地形的像素，阴影贴图跳过光照范围外的区块。纹理精度、阴影分辨率和视距设置保持原值。

## 玩法

1. **漫游**：连续生成的森林、樱花林、大型冰川雪谷与群峰、沙漠、海岸和洞穴；有昼夜、远山、动物和环境声音。狐狸多见于林地，山羊出现在雪山，青蛙会在湿润地带现身。
2. **造景**：快捷栏预置草、木、玻璃、樱花、苔藓与灯光。打开素材盘还能选更多材料。方块无限使用，拆除约需 0.18 秒，无工具耐久与掉落管理。
3. **留影**：进入拍照模式后拖动取景、调镜头，照片保存到当前浏览器的相册。相册支持下载、删除；每个世界最多保留 10 张。
4. **雪谷补给站**：雪山旁的石砌房屋里有补给箱、工作台、储物架和紫色传送门。靠近补给箱按 `R` 打开，点哪一样就拿哪一样，不再一键收空。补给只领取一次，领取记录随世界保存。
5. **下界**：直接走进房屋里的紫色传送门就会抵达下界，不需要按任何按钮。那里有熔岩海、灵魂沙峡谷、玄武岩三角洲、绯红与诡异菌林，以及游荡的余烬兽。下界出口旁的传送门同样走进去就能返回雪谷房屋。
6. **偶遇**：世界里还埋着六个不进入任何列表的彩蛋——画架、会回答的井、海边的鞋、石堆里的钥匙，以及只在深夜或某个夜里出现两次的邂逅。走到附近按 `R`，或者举起相机。细节见 `SPOILERS.md`。

世界与照片都保存在本机浏览器。栖野使用新的 `mcweb.landscape.v2` 存档键；原有远野存档 `mcweb.save.v1` 不会被覆盖。

## 电脑界面

探险界面让世界占据画面中央：左上显示地点与时间，右上是可收起的手绘地图，左侧是紧凑的工具轨，底部是 9 格快捷栏。靠近可以互动的物件时，画面下方会出现提示。

| 操作 | 功能 |
| --- | --- |
| `WASD`、鼠标 | 移动、环顾 |
| 左键按住、右键 | 拆除、放置 |
| `1`–`9`、滚轮 | 切换快捷材料 |
| `E` | 景观素材 |
| `R` | 打开雪谷补给箱（走进传送门即自动穿越） |
| `Tab` | 释放鼠标，点击左侧工具；再按一次返回视角控制 |
| `P` | 拍照；拍照模式中拖动取景，`Enter` 或空格拍摄 |
| `G` | 风景相册 |
| `T` | 切换正午、黄昏、星夜、晨光 |
| `F`、`M` | 飞行、手绘地图 |
| `Esc` | 关闭面板或暂停 |

## 手机界面

触屏设备会自动显示另一套布局：左半屏是浮动摇杆，手指落在哪里摇杆就出现在哪里；右侧空白区域拖动视角。右下角是一个主操作按钮——**短按放置方块，长按拆除方块**，旁边是跳跃、飞行、素材与暂停。右上角有可展开的地图，以及独立的**拍照、相册、时光**按钮。靠近补给箱时，点画面下方的互动按钮即可打开。走进紫色传送门会自动穿越。底部快捷栏可以直接点选材料。

如果设备检测不准确，可在开始菜单切换「操作：自动 / 手机触屏 / 键鼠」。

## 启动

```bash
open index.html
```

需要支持 WebGL2 的现代浏览器。画面设置可调整视距、清晰度、阴影、粒子和视角。`?seed=文字或数字` 可以指定世界种子，`?auto=1` 可跳过开始菜单。

## 项目结构

- `index.html`：游戏外壳与两套界面
- `css/studio.css`：栖野的菜单、素材盘、拍照、相册及触屏布局
- `css/field-ui.css`：新版观景手册界面及电脑、手机操作布局
- `css/expedition-ui.css`：探险界面的电脑、手机布局与补给箱面板
- `css/redesign.css`：世界 HUD 与基础界面样式
- `js/world.js`、`js/renderer.js` 等：地形、体素渲染与模拟
- `js/batch.js`：区块网格的共享大缓冲、区间分配与批量提交
- `js/terrain-worker.js`：后台生成新区块与完整体素网格
- `js/main.js`：输入、建造、拍照、相册与存档
- `js/secrets.js`：六个不进入任何列表的彩蛋（地点、夜里的事件与联动）
- `tests/verify.js`：无依赖的世界逻辑检查
- `tests/terrain-worker-check.cjs`：后台结果与原实现逐字节对照
- `tests/mesh-bench.cjs`：统计区块网格规模与可见批次，衡量批处理效果

项目不包含 Mojang 官方贴图或音效。
